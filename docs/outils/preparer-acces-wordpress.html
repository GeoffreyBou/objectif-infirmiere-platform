Préparer l’accès WordPress

Ce fichier fonctionne localement dans votre navigateur. Il n’envoie aucune donnée sur Internet et ne conserve pas votre mot de passe.

Il prépare l’authentification du compte dev-agent pour le site app-dev.objectif-infirmiere.fr.

Utilisez le mot de passe d’application créé dans le profil WordPress, pas votre mot de passe habituel.

Collez ensuite le résultat dans la valeur du secret réseau OI_WP_AUTHORIZATION de l’environnement Codex. Ne le collez jamais dans le chat : il contient votre accès, même sous forme encodée.
